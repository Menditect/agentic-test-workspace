# Menditect Agent Workspace Template - Release Notes

## Version v1.10.2

> Released on: 2026-10-02

### Release Summary
improved linting rules

### Detailed Changes
- **Linter Runner Dispatcher & Custom Overrides (`tools/run-linter.mjs`)**:
  - Added `tools/run-linter.mjs` runner dispatcher that automatically detects and executes local custom linter overrides (`tools/mta-lint.custom.mjs`) when present (`PAT-113`, `ANTI-62`), protecting user hotfixes from being overwritten during updates.
  - Routed all npm lint scripts in `package.json` (`lint:plan`, `lint:audit`, `lint:config`, `lint:test`) through the runner dispatcher.
- **Enhanced Linter Validation Rules (`tools/mta-lint.mjs`)**:
  - **PAT-07 & ANTI-48 (Empty/Null Boundary Handling)**: Validates that execution plans testing empty object or unassigned association boundaries include a `Retrieve-from-Teststep` sentinel retrieve step in the Master Step Ledger using short sentinel values (`NONE`, `NULL`, `VALID`).
  - **PAT-08 (Sentinel Count Assertion)**: Validates that sentinel retrieve steps include an embedded `Assert Object Count` check.
  - **ANTI-20 (Frontend Isolation)**: Refined frontend UI vs backend microflow substitution checks to properly permit `MenditectMxFrontendTestKit` and `MenditectPlaywrightConnector` calls.
  - **Flexible Scenario Columns**: Expanded variation matrix column matching to support diverse header formats (e.g. `#1`, `Scenario #1`).
  - Added new test fixtures (`invalid_empty_object_no_sentinel.md`, `invalid_frontend_anti20.md`, `valid_frontend_plan.md`, `valid_plan_with_sentinel.md`) and expanded internal self-test coverage to 14/14 passing tests.
- **Upstream Sync Engine (`scripts/sync-upstream.js`)**:
  - Enhanced tooling sync to pull `run-linter.mjs` and the expanded fixture suite while preserving local `mta-lint.custom.mjs` overrides.
- **Directives & Contribution Policy (`AGENTS.md`, `GEMINI.md`, `CONTRIBUTING.md`)**:
  - Formalized the **Skills & Tools Immutability & Customization Rule (PAT-113, ANTI-62)** and the **Upstream Feedback & Contribution Protocol** directing bug reports and feedback to `support@menditect.com`.
