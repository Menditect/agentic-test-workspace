### Detailed Changes
- **PreToolUse Hook & MCP Proxy Guard (`tools/mta-hook-gate.mjs`):** Enforced active conversational state machine gates, preventing mutating tool calls and ad-hoc execution scripts before explicit human approval.
- **Two-Turn Gate Ledger (`.mta-gate-ledger.json`):** Hardened Gate 1 and Gate 2 placement staging and verification via `mta-lint.mjs stage-placement` and `pre-build` / `pre-exec`.
- **Frontend & Architectural Linters:** Added validation for high-level frontend locator generators (`ANTI-79`), dynamic piping (`PAT-32`), test data teardown (`PAT-92`), and Studio Pro MCP offline fallback guards (`ANTI-75`).
- **Expanded Self-Test Suite:** Updated `tools/run-linter.mjs self-test` to 84/84 passing automated checks across backend, frontend, audit, and hook gates.
- **Orchestrator Parity:** Synchronized `AGENTS.md` to version 4.50.0.
