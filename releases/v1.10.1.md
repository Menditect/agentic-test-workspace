### Detailed Changes
- **Linter Engine Upgrade (`tools/mta-lint.mjs` v1.1.0):** Enhanced the post-construction smoke audit to perform value-by-value reconciliation of scenario names, scenario descriptions, step descriptions with pattern tags (`PAT-*`), and test case descriptions against the Execution Plan.
- **Upstream Sync Integration:** Enhanced `scripts/sync-upstream.js` so that `npm run update:skills` and `npm run update` automatically synchronize and self-test `tools/mta-lint.mjs`.
- **Standalone Tool Sync Command:** Added `scripts/sync-tools.js` and `npm run update:tools` npm script.
- **Update Checker:** Added MTA linter version checking and reporting to `npm run update:check`.
