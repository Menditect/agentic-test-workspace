# Menditect Agent Workspace Template - Release Notes

## Version v1.10.8

> Released on: 2026-10-20

### Release Summary
improved linters for datavariation

---

### Detailed Changes
- **PAT-06 CreateObject Input Handle Restriction:** Enforced that `CreateObject` steps cannot specify an input handle (input handle must be `-`). Object associations must be configured via the parameters and bindings column (e.g., `Car_CarSize = step1_CarSize`), preventing invalid input handle definitions (`INVALID_CREATE_OBJECT_INPUT_HANDLE`).
- **PAT-07 & ANTI-48 Mandatory Sentinel Boundaries for Backend Unit Tests:** Added strict linter checks requiring backend unit tests creating objects for microflow execution to include empty/null parameter variation testing in Section 4 (setting Sentinel to `'NONE'` or unassigned).
- **Direct CreateObject to Microflow Handle Guard:** Prevented microflows from directly consuming `CreateObject` handles instead of PAT-07 filtered `RetrieveObject` handles when boundary variations are tested.
- **Fixture & Self-Test Expansion:** Added new fixtures `invalid_backend_no_sentinel_empty.md` and `invalid_create_object_with_input_handle.md` and updated existing fixtures, expanding the self-test suite to 34 passing checks (`npm run lint:test`). Bumped linter engine version to v1.4.2.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run update:skills` and `npm run update:mxcli` to ensure dependencies are current.
