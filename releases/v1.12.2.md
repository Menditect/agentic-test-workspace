# Menditect Agent Workspace Template - Release Notes

## Version v1.12.2

> Released on: 2026-11-10

### Release Summary
Hotfix for free exploratory testing mode and license tier enum alignment.

---

### Detailed Changes
- **Free Exploratory Testing MCP Stub (`mta-proxy.js`)**:
  - Unauthenticated `mta` proxy requests without an `MTA_MCP_AUTH_HEADER` now return an exploratory stub `{ tools: [] }` for `tools/list` and `initialize` instead of raising HTTP 401/404 errors.
  - Prevents IDE MCP connection crashes in free exploratory testing mode where no MTA cloud service account token is required.
- **Child Workspace Environment Loading (`mta-proxy.js`)**:
  - `refreshConfigAndEnv()` now explicitly loads `.env` and `.env.local` from `config.workspace_dir` when operating in Central Tools Hub mode (`[1]`).
- **License Tier Enum Alignment (`setup.js`)**:
  - Normalized `mta_license_tier` to standard values `"free_exploratory"` / `"paid_enterprise"` (mapping legacy `"exploratory_free"`, `"free"`, `"paid"`, and `"enterprise"` aliases automatically).

---

### Upgrading / Migration Notes
No breaking changes. Free exploratory users can run `npm run setup` or start their IDE without encountering 401 connection errors on the `mta` proxy server.
