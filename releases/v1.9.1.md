# Menditect Agent Workspace Template - Release Notes

## Version v1.9.1

> Released on: 2026-09-29

### Release Summary
improved documentation in script and verify mode

---

### Detailed Changes
- **Universal Default Value Guidance in Setup Wizard (`scripts/setup.js`)**:
  - Updated the interactive `ask()` prompt helper so that whenever a default value in `[...]` is available, the prompt explicitly instructs the user `(Press Enter to accept, or 'b' to go back)` or `(Press Enter to accept)`.
- **In-Script Documentation for Exploratory Testing (`scripts/setup.js`)**:
  - Added contextual guidance at the **MTA URL** prompt explaining that cloud MTA URL is not required for free local exploratory testing.
  - Added a prominent notice at the **Identification token for a service account** prompt to **Press Enter to SKIP (leave blank)** for users without MTA Cloud accounts.
- **Color-Coded Status Output in Verify Mode (`scripts/verify-setup.js`)**:
  - Formatted `[PASS]` tags in green, `[FAIL]` tags in red, and `[WARN]` tags in yellow using ANSI color codes.
  - Styled `Verification Complete.` and `Verification Failed.` summary headers in bold green and bold red for immediate visual clarity.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run update:skills` and `npm run update:mxcli` to ensure dependencies are current.
