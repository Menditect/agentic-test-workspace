# Menditect Agent Workspace Template - Release Notes

## Version v1.10.5

> Released on: 2026-10-07

### Release Summary
improved updating of skills and linter tools

---

### Detailed Changes
- **Coupled Skill & Linter Synchronization (`scripts/sync-upstream.js`)**:
  - Automatically synchronizes MTA linter tooling (`tools/mta-lint.mjs`) and test fixtures whenever skills are updated (`npm run update:skills`), eliminating version skew between testing prompt guidelines and plan verification rules.
  - Full workspace update (`npm run update`) now automatically bundles `skills`, `tools`, and `mxcli` in a single command.
- **Removed Standalone Tool Sync**:
  - Removed redundant `npm run update:tools` npm script and `scripts/sync-tools.js`.
- **Documentation & Directives Alignment**:
  - Updated `README.md` to document the automatic lockstep synchronization between skills and linter tools.
  - Aligned immutability and update directives in `AGENTS.md` and `GEMINI.md`.
- **Linter Engine & Intent Matrix Validations (`tools/mta-lint.mjs`)**:
  - Added non-circular ground truth specification checks (`ANTI-69`, `ANTI-71`).
  - Added non-trivial boundary risk coverage verification (`ANTI-70`).
  - Added return assertion presence guardrails (`ANTI-72`).
  - Expanded internal linter self-test suite to **25/25 passing checks**.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run update:skills` to update both skills and linter tools in a single command.
