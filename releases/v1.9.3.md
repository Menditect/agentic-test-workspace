# Menditect Agent Workspace Template - Release Notes

## Version v1.9.3

> Released on: 2026-09-30

### Release Summary
improved mta_config with links to documentation

---

### Detailed Changes
- **Menditect Documentation & LLMs.txt Integration (`mta_config.schema.json`, `README.md`)**:
  - Added `documentation_url` (default: `https://documentation.menditect.com`) to the canonical `mta_config` schema (v1.9.0) and documentation.
  - Added `llms_txt_url` (default: `${documentation_url}/llms.txt`) to support machine-readable documentation discovery for AI assistants according to the llmstxt.org specification.
  - Bundled pre-indexed documentation catalog in `docs/mta_docs_index.json`.
- **Setup & Persistence (`scripts/setup.js`)**:
  - Updated configuration generation to include default documentation endpoints.
  - Added `documentation_url` and `llms_txt_url` aliases to `normalizeConfigAliases`.
- **Workspace Diagnostics (`scripts/verify-setup.js`)**:
  - Added `checkDocumentationSettings()` to verify active documentation endpoints during `npm run verify`.

---

### Upgrading / Migration Notes
No breaking changes. Workspaces automatically default to `https://documentation.menditect.com` and `https://documentation.menditect.com/llms.txt`. Run `npm run update:skills` and `npm run update:mxcli` to ensure dependencies are current.
