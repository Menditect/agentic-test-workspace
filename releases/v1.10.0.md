# Menditect Agent Workspace Template - Release Notes

## Version v1.10.0

> Released on: 2026-10-01

### Release Summary
added linter tools for checking execution plan and smoke audit in agentic mode

---

### Detailed Changes
- **Execution Plan & Smoke Audit Linter Tooling (`mta-lint`)**:
  - Added standalone CLI linter tool `tools/mta-lint.mjs` for validating test execution plans and server test construction responses without external dependencies.
  - Implemented `lint:plan` (`mta-lint plan <file>`) to validate execution plan structure, table schemas, metadata, and anti-pattern rules (e.g. `ANTI-01` action names, `ANTI-48` association matrix bindings, handle scoping).
  - Implemented `lint:audit` (`mta-lint audit <plan.md> <server.json>`) for 4-phase smoke audit reconciliation (step count parity, variation item registration, scenario metadata, and `TCER_TestConstructionErrors == 0` validation).
  - Added `lint:config` (`mta-lint config [path]`) to validate `mta_config.json` against required fields and license tiers.
  - Included a built-in self-test suite and fixtures in `tools/fixtures/` (`valid_plan.md`, `invalid_matrix_assoc.md`, `invalid_step_anti01.md`, pass/fail server responses).
  - Integrated linter verification into `scripts/verify-setup.js` (`[PASS] MTA Linter tooling is ready`).
  - Exposed convenient npm scripts in `package.json`: `npm run lint:plan`, `npm run lint:audit`, `npm run lint:config`, and `npm run lint:test`.
