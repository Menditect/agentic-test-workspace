# Menditect Agent Workspace Template - Release Notes

## Version v1.12.1

> Released on: 2026-11-09

### Release Summary
fixed bug in verify script for multi app configuration setup

---

### Detailed Changes
- **Multi-Workspace Auto-Discovery in `verify-setup.js`**:
  - Automatically resolves target app workspaces in Option `[1]` (Central Tools Hub) architectures by inspecting CLI arguments, `MTA_CONFIG_PATH`, `.mxcli/workspaces.json` hub registry, global IDE MCP configs, and parent/sibling workspaces.
  - Interactive numbered selection menu (`[1..N]`) presented when running `npm run verify` in an interactive terminal (TTY) with multiple configured app workspaces.
  - Direct CLI argument support: `npm run verify -- <path-to-app-workspace>` or `node scripts/verify-setup.js <path>` to target a specific app workspace.
- **Environment & Credential Isolation**:
  - Removed top-level ambient `.env` loading from `scripts/setup.js` import to eliminate credential leakage into external verification runs.
  - Verification now strictly loads `.env` and `.env.local` from the selected target workspace directory.
- **Documentation**:
  - Added dedicated `## Workspace Verification & Diagnostics` section to `README.md` documenting verification commands, interactive selection, local runner scripts (`verify.bat` / `./verify`), and diagnostic checks.
