# Menditect Agent Workspace Template - Release Notes

## Version v1.9.2

> Released on: 2026-09-30

### Release Summary
updated script to set auto approve execution plan settings for exploratory tests

---

### Detailed Changes
- **Exploratory Testing Strategy in Setup Wizard (`scripts/setup.js`)**:
  - Added dedicated interactive step (`exploratory_mode`) to configure `exploratory_execution_mode` in `mta_config.json`.
  - Configures execution strategy between `auto_execute` (default: 1-turn high-velocity local execution with automatic database rollback) and `prompt_approval` (pauses at Checkpoint 1 for explicit approval before dispatching).
  - Integrated into the setup summary review menu (`[9] Exploratory Mode`) with direct jump-to-edit capability.
  - Persists `exploratory_execution_mode` to `mta_config.json` during workspace initialization.
- **Contract & Schema Documentation (`mta_config.schema.json`, `README.md`)**:
  - Documented the `exploratory_execution_mode` property in `mta_config.schema.json` and `README.md`.
- **Release Automation Tooling (`scripts/create-release.js`)**:
  - Improved line-ending compatibility (CRLF / LF) when updating `RELEASES.md` during release preparation.

---

### Upgrading / Migration Notes
No breaking changes. Existing workspaces default to `auto_execute` if unspecified. Run `npm run update:skills` and `npm run update:mxcli` to ensure dependencies are current.
