# Menditect Agent Workspace Template - Release Notes

## Version v1.8.5

> Released on: 2026-09-28

### Release Summary
improved support for studiopro MCP

---

### Detailed Changes
- **Studio Pro MCP Interactive Configuration**:
  - Setup wizard interactively prompts for the Studio Pro MCP URL when Studio Pro MCP is selected.
  - Added visual instruction box guiding the user to enable the MCP Server inside Mendix Studio Pro (`Edit > Preferences`).
  - Added clear notification that `mxcli` continues to be used in the background for project discovery, instance detection, and scaffolding.
- **Automated Configuration Persistence**:
  - Automatically persists `studiopro_mcp_url` into `mta_config.json`.
  - Automatically exports `STUDIOPRO_MCP_URL` into `.env`.
  - Configures `StudioPro` MCP server integration across IDE configurations (VS Code, Cursor, Claude, Antigravity, and Claude Desktop).
- **Setup & Documentation UX Improvements**:
  - Added "What is an Agentic Test Workspace?" section to `README.md` explaining the workspace role for AI assistants.
  - Clarified in `README.md` and `scripts/setup.js` that directory paths are customizable examples.
  - Fixed directory navigation in `README.md` by explicitly including `cd` into the created workspace directory before cloning.
  - Clarified that the local SQLite database index (`.mxcli/catalog.db`) is an optional offline search index.
- **Configuration Contract**:
  - Added `studiopro_mcp_url` property definition to `mta_config.schema.json`.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run update:skills` and `npm run update:mxcli` to ensure dependencies are current.
