### Detailed Changes
- **Improved Setup for Exploratory Testing**:
  - Updated agent directives in `scripts/setup.js` and `README.md` to clarify native MCP tool execution mandates and safe execution defaults (`RollbackTcseAfterExecution: "Yes"`, `ExecutorUsername: "MxAdmin"`, `ApplySecurityExecutor: "NONE"`).
  - Added explicit directives explaining MTA License Tiers (`free_exploratory` vs `paid_enterprise`) and their capabilities (local in-memory microflow testing vs persistent cloud test suites and Playwright UI testing).
  - Added support for `mta_license_tier` in `mta_config.schema.json` (bumped to v1.10.0) with alias normalization in `scripts/setup.js`.
