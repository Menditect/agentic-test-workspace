### Detailed Changes
- **Assertion Filtering in PAT-07 Empty Boundary Checks:** Updated `validatePat07EmptyBoundaries` in `tools/mta-lint.mjs` to bypass assertion rows (`Assert Return`, `Assert Count`, `Assert Feedback`, `Assert Value`, `Assert Attribute`), preventing false-positive PAT-07/ANTI-48 empty sentinel boundary violations when asserting empty return values in test variations.
- **Robust Sentinel Entity Candidate Matching:** Enhanced sentinel entity resolution when scanning scenario headers and descriptions for empty/unassigned boundary cases by prioritizing registered sentinel entities and filtering out common stop words (`Unassigned`, `Empty`, `Null`, `None`, etc.).
- **Backend Unit Test Step Ledger Flexibility:** Allowed compact 8-column ledgers for backend unit tests by relaxing the mandatory `case` column requirement and supporting flexible column synonyms (`in`, `out`, `binding`, `exec`).
- **Linter Engine & Regression Suite:** Bumped linter engine to v1.4.1 and added `valid_plan_null_assert_compact_ledger.md` regression fixture to `npm run lint:test` (32 passing checks).
