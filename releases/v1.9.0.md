# Menditect Agent Workspace Template - Release Notes

## Version v1.9.0

> Released on: 2026-09-28

### Release Summary
improved navigation in script

---

### Detailed Changes
- **Interactive Step Navigation**: Enabled backtracking (`b` or `back`) across all setup wizard questions to easily review or change answers.
- **Pre-Save Configuration Summary & Review**: Added a numbered configuration review table before files (`mta_config.json`, `.env`) are saved, allowing users to jump directly to any setting and edit it.
- **Conditional Indexing Bypass**: Automatically bypasses the offline SQLite catalog indexing prompt when Studio Pro MCP is selected as the model inspection source.
- **Clear User Guidance**: Added explicit navigation hints in the header, prompt questions, and setup documentation in `README.md`.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run setup` to reconfigure or update your workspace.
