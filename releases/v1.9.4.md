# Menditect Agent Workspace Template - Release Notes

## Version v1.9.4

> Released on: 2026-10-01

### Release Summary
streamlined core mta mcp tools in mta_proxy

---

### Detailed Changes
- **Streamlined `CORE_TOOLS` in `mta-proxy.js`**:
  - Aligned the proxy's `CORE_TOOLS` registry to exactly match the 51 live tools exposed by the upstream MTA Primitive MCP server (`/primitivetools/mcp`).
  - Pruned 19 phantom/composite tool references (such as `GetExecutionPlan`, `ExecuteTestCase`, and `CreateTestStepPersist`) that were not exposed by the cloud server.
  - Ensures tool filtering (`FILTER_TOOLS=true`) and priority sorting in `tools/list` operate strictly over real, functional primitive MTA tools without cluttering agent tool contexts.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run update:skills` and `npm run update:mxcli` to ensure dependencies are current.
